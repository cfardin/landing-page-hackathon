# Heaven Furniture Mart — Landing Page

Conversion-focused landing page for **Heaven Furniture Mart**, a bespoke furniture and interior styling brand based in Chattogram, Bangladesh. Built for the RACDOX Hackathon.

**Live:** https://landing-page-topaz-gamma-52.vercel.app/

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS
- next/image for optimized image delivery

## Sections

- **Navbar** — sticky, responsive, mobile menu
- **Hero** — brand statement + featured product image
- **Brand Intro** — "The Heaven Approach"
- **Why Choose Heaven** — trust points
- **Collections** — Living, Bedroom, Dining, Bespoke
- **Bespoke Highlight** — the brand's core differentiator
- **Social Proof** — MD quote + showroom photo
- **Gallery** — expandable grid with image modal
- **Milestones** — brand timeline, 2020–2026
- **Contact & Footer** — address, WhatsApp CTA, embedded map, socials

## Getting Started

```bash
git clone https://github.com/cfardin/landing-page-hackathon.git
cd landing-page-hackathon
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deployment

Deployed on [Vercel](https://vercel.com/).
